VidCatch

Privacy Policy

Last updated: 2026-09-01

Product: VidCatch browser extension (Chrome / Edge, Manifest V3)

1. Overview

VidCatch helps you detect video streams on webpages you visit and download them to your computer through a side panel. This policy explains what data is handled and why.

2. Data we process

2.1 Processed on your device (local)

The extension may store locally in browser storage:

  • Detected media metadata for the current tab (URL, title, thumbnail, quality options, DRM flag)
  • Download job status and history
  • User settings (e.g. save-as preference, history limit, naming patterns)
  • Optional in-extension rating / feedback UI state

This data stays in your browser profile unless you clear extension storage or uninstall.

2.2 Permissions-related access (not sold)

To detect and download media, the extension may:

  • Observe network requests on pages you visit (to find media URLs)
  • Read page/tab context needed for the current download
  • Access cookies for sites involved in a download when assembling authenticated media requests (e.g. some CDN links)
  • Write files via the browser Downloads API to your download folder

We do not use this access to build advertising profiles.

2.3 Network / remote servers

In the current shipped configuration, remote product APIs are disabled. The extension does not register accounts or sync download history to a VidCatch server by default.

When you download a video, your browser / the extension may request media URLs from third-party sites you already opened (the video host or its CDN). Those requests are subject to those sites’ own policies.

If you later enable optional cloud features (license check, feedback upload, etc.), this policy will be updated and the store listing will disclose the new endpoints.

3. What we do not collect

  • We do not sell personal data
  • We do not use detected media content for advertising
  • We do not require an account for basic local download features in the current version

4. Children

VidCatch is not directed at children under 13. Do not use the extension if you are under the age required in your jurisdiction for this type of software.

5. Data retention

Local data remains until you clear it in the extension (e.g. history), clear browser data, or uninstall. Remote retention applies only if cloud features are enabled in a future version (none by default today).

6. Your choices

  • Clear download history in the side panel Settings / History
  • Revoke permissions or uninstall via chrome://extensions / Edge extensions page
  • Restrict site access in the browser’s extension details (may limit detection)

7. Third-party services

Media files and pages come from websites you visit. VidCatch does not control those sites. Respect copyright and the terms of each website. DRM-protected content cannot be downloaded.

8. Changes

We may update this policy. The “Last updated” date will change; material changes will be reflected on the store listing when required.

9. Contact

If you have questions about this privacy policy, please use the support options provided on the extension’s Chrome Web Store or Microsoft Edge Add-ons listing.
