Amazon Review Exporter

Privacy Policy

Last updated: May 4, 2026

This Privacy Policy describes how the Amazon Review Exporter browser extension ("Amazon Review Exporter", "the Extension", "we", "us", or "our") handles information when you install and use the Extension.

Amazon Review Exporter is designed to let users export Amazon product review data into CSV files. The Extension is intended to perform this function locally in the user's browser with minimal data collection and minimal retention.

1. Scope

This Privacy Policy applies to the Amazon Review Exporter browser extension, including its popup UI, background processes, content scripts, and local storage used to support review scraping and CSV export.

This Privacy Policy does not apply to:

  • Amazon's own websites, services, or privacy practices
  • Your browser vendor's privacy practices
  • Any third-party websites that you visit outside the Extension

2. Summary

  • The Extension reads review-related content from supported Amazon product and review pages when you actively use the Extension.
  • The Extension stores scrape state and scraped review data locally in your browser so it can complete export tasks.
  • The Extension generates CSV files locally and triggers a browser download to your device.
  • The Extension does not sell user data.
  • The Extension does not use user data for advertising, profiling, or analytics.
  • The Extension does not transmit scraped review data to our servers.
  • The Extension currently validates and stores any License Key locally and does not send it to a remote validation server.

3. Information We Handle

Depending on how you use the Extension, the Extension may access or process the following categories of data.

3.1 Amazon page and review content

When you use the Extension on a supported Amazon page, the Extension may access and process page content that is necessary to provide its user-facing functionality, including:

  • Amazon page URL
  • Amazon marketplace domain
  • ASIN
  • Product title
  • Review title
  • Review body text
  • Review author display name
  • Review date text
  • Review rating text
  • Helpful vote count
  • Verified purchase status
  • Review image URLs, if present
  • Product variant information shown in the review context, such as color, size, style, or configuration

This information is processed only to provide the Extension's review scraping and CSV export functionality.

3.2 Browser tab and task state information

To start, continue, stop, and complete an export task, the Extension may process:

  • The active tab ID
  • The active tab URL
  • Review page navigation state
  • Scrape progress state such as current page, total reviews, and task status

3.3 Local configuration information

The Extension may store limited local configuration or state information, including:

  • Whether an export task is in progress
  • Cached scraped review records
  • License Key entered by the user
  • Locally computed License status

3.4 Information We Do Not Intentionally Collect

The Extension is not designed to collect or process:

  • Passwords
  • Payment card information
  • Authentication cookies
  • Personal emails or messages
  • Contacts
  • Health data
  • Precise geolocation

The Extension is also not designed to read unrelated browsing content outside supported Amazon pages for its core functionality.

4. How We Use Information

We use the information handled by the Extension solely to provide and support the Extension's single user-facing purpose: exporting Amazon review data into CSV files.

More specifically, the Extension uses information to:

  • Detect whether the current page is a supported Amazon product page or review page
  • Build or open the correct Amazon review page for the selected product
  • Read review content from the page
  • Continue scraping across review pages when needed
  • Store in-progress task state locally so exports can continue reliably
  • Generate CSV content locally
  • Trigger a file download in the browser
  • Store and apply local License status, if the user enters a License Key

We do not use handled data to:

  • Build advertising profiles
  • Serve personalized ads
  • Retarget users
  • Sell or rent data
  • Create unrelated analytics datasets
  • Train models on your data

5. Where Data Is Stored

The Extension is designed to store operational data locally in the user's browser environment.

This may include:

  • Review scrape task state stored in browser extension local storage
  • Scraped review records stored in browser extension local storage
  • License Key and local License state stored in browser extension local storage
  • Exported CSV files downloaded to the user's device through the browser download flow

6. Data Transmission and Sharing

6.1 Transmission to our servers

At the time of this policy's last update, the Extension does not transmit scraped review content, exported CSV content, or browser task state to our servers.

At the time of this policy's last update, the Extension also does not use a remote server to validate License Keys. License validation is handled locally by the Extension code.

6.2 Sharing with third parties

We do not sell, rent, or transfer handled data to data brokers, advertisers, or analytics providers.

The Extension may interact with:

  • Amazon pages that the user visits
  • The browser's extension APIs, such as storage, tabs, and downloads

The Extension's CSV export is initiated through the browser's built-in download system, which saves the file to the user's device or user-selected download location.

6.3 Legal or security disclosures

If we are legally required to disclose information, we may do so only to the extent required by applicable law, regulation, legal process, or enforceable governmental request.

7. Permissions and Why They Are Needed

The Extension may request permissions such as the following:

7.1 storage

Used to store:

  • In-progress scrape state
  • Cached review records before export
  • License Key and local License status

7.2 tabs

Used to:

  • Read the active Amazon tab URL
  • Navigate to the product's review page when the user starts an export
  • Continue the export workflow on the relevant Amazon review tab

7.3 downloads

Used to:

  • Trigger CSV downloads generated by the Extension

7.4 Amazon host permissions

Used to:

  • Access supported Amazon product and review pages
  • Read the review data needed for the export feature on those pages

8. Retention

The Extension retains locally stored data only as long as needed to support its functionality or until the data is replaced, cleared, or removed by the user.

Examples:

  • In-progress scrape state may remain in local extension storage until the task completes, is reset, or is overwritten.
  • Cached review records may remain in local extension storage until a new task resets them or the user removes the Extension or clears extension data.
  • Exported CSV files remain on the user's device until the user deletes them.
  • A locally stored License Key may remain until the user clears extension data, removes the Extension, or overwrites the key.

9. User Control and Choices

Users control whether and when the Extension is used.

You can:

  • Start an export only when you choose to do so
  • Stop an in-progress export from the Extension UI
  • Remove downloaded CSV files from your device at any time
  • Remove the Extension from your browser
  • Clear browser extension storage through your browser's extension management or site/browser data controls, where applicable

If you uninstall the Extension, browser-managed extension storage associated with the Extension is generally removed by the browser, subject to browser behavior and sync settings.

10. Children's Privacy

The Extension is not directed to children under 13, and we do not knowingly design it to collect personal information from children.

11. Security

We seek to minimize privacy risk by limiting handled data to what is necessary for the Extension's single purpose and by keeping operational data local where possible.

However, no software, browser environment, storage system, or transmission method can be guaranteed to be 100% secure. Users should avoid using browser extensions in environments they do not trust.

12. International Users

If you use the Extension outside your home jurisdiction, you understand that locally handled data may still be subject to the laws and technical behavior of your browser platform, device, and the websites you visit.

Because the Extension is designed to operate locally and not send scraped review data to our servers, cross-border transfer by us is intentionally minimized.
